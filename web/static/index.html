How it works

01
Sparse rating matrix
The 100k user ratings are stored as a sparse user-item matrix where each cell holds a 1–5 star rating.
02
KNN + cosine similarity
A K-Nearest Neighbours model computes cosine similarity between movie vectors to find the closest matches.
03
Live metadata enrichment
Posters, genres, ratings, and plot summaries are pulled in real-time from the OMDb API for each result.
04
FastAPI inference server
A lightweight Python backend loads the pre-built pickle model and serves recommendations in milliseconds.
